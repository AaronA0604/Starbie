This is a starboy-like device. I shaped it like a duck, since I plan on expanding it to be used as a debugging tool where in addition to its starboy features, it can detect if someone is speaking to it and respond in simple prompting sentences.

Controls
| Control | What it does |
|---|---|
| Button 1, first press | Opens the radial menu |
| Tilt while menu is open | Moves the selector ball; each general direction corresponds to one large sector |
| Button 1, second press | Chooses the highlighted action |
| Button 2 | Shows or hides the stats screen |
| Shake while viewing the pet | Triggers Starbie's shake reaction |
